## 生成原型与剩余条件

`generate.py` 接受显式本地基础权重和 LoRA 目录，关闭隐式凭据使用及远程加载。它重用上游拒绝采样和回退，限制块数、回退次数和进程耗时；来源记录包含代码版本、权重哈希和种子。候选继续经过同一 Go 导入与校验命令，不保存产品作品。

当前默认 Hugging Face 缓存中没有 `meta-llama/Llama-3.2-1B-Instruct`。实跑预检返回 `base_model_missing`，未安装或启动模型推理栈，未购买许可证。需要获授权的本地基础模型目录和公开 BrickGPT LoRA 文件后，才能执行真实文本生成。Python 契约测试的子进程输出是测试创建的夹具，不是模型输出。
